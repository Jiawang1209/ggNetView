# Alternative four-stage environmental dataset

A second, slightly smaller variant of \[Envdf_4st\] used to exercise
multi-block alignment functions.

## Usage

``` r
Envdf_4st_2
```

## Format

A \`data.frame\` with 18 rows and 56 columns.

## Source

Internal example data shipped with ggNetView.

## Examples

``` r
data(Envdf_4st_2)
dim(Envdf_4st_2)
#> [1] 18 56
```
