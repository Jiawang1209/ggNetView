# Fungal ASV demonstration table

A small subset of fungal Amplicon Sequence Variants used together with
\[BASV_tab\] for cross-domain network examples.

## Usage

``` r
FASV_tab
```

## Format

A \`data.frame\` with 50 rows and 10 columns.

## Source

Internal example data shipped with ggNetView.
