# Sample metadata for the OTU example

Sample-level metadata accompanying \[otu_tab\].

## Usage

``` r
otu_sample
```

## Format

A \`data.frame\` with 18 rows (samples) and 2 columns.

## Source

Internal example data shipped with ggNetView.

## Examples

``` r
data(otu_sample)
head(otu_sample)
#>   Sample Group
#> 1    KO1    KO
#> 2    KO2    KO
#> 3    KO3    KO
#> 4    KO4    KO
#> 5    KO5    KO
#> 6    KO6    KO
```
